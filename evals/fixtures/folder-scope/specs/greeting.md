# Greeting card text

A small script prints a greeting card text for a name and an occasion.

## Requirements

1. `greet(name, occasion)` returns one line: "Happy <occasion>, <name>!".
2. A blank name prints "Happy <occasion>!" with no comma.
3. A command line entry reads the name and the occasion from its two arguments.
4. Unit tests cover both forms of the line.
